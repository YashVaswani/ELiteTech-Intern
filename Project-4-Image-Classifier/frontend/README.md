# Frontend

React + TypeScript + Vite single-page app for the Cat vs Dog Classifier.
See the [repo root README](../README.md) for full setup, and the
[backend](../backend) for the API this talks to.

```bash
npm install
cp .env.example .env.local
npm run dev      # http://localhost:5173
npm run lint
npm run test
npm run build
```

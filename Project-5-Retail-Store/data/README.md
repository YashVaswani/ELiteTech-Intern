# Data

Nothing in `raw/` or `processed/` is committed (see `.gitignore`) - it's all
regenerated by running the pipeline, so the repo stays small and free of any
customer data.

- `raw/transactions.csv` - one row per order (`customer_id`, `invoice_date`, `amount`).
  Created automatically by `retail-segment train` if it doesn't exist yet, using
  a synthetic transaction generator (see `src/retail_segmentation/data.py`).
- `processed/rfm_features.csv` - one row per customer: Recency, Frequency, Monetary.
- `processed/customers_segmented.csv` - the same, plus the assigned `cluster` and `segment`.

## Using your own data

Drop a real export at `data/raw/transactions.csv` with columns `customer_id`,
`invoice_date`, `amount` before running `retail-segment train`, and the
pipeline will use it instead of generating synthetic data.

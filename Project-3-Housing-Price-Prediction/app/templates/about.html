How It Works & Regional Calibration

When you input details on the home page, the application:

  1. Parses and validates user inputs (Area, Bedrooms, Bathrooms).
  2. Standardizes the features using parameters from the training-set StandardScaler.
  3. Predicts the base price using the trained OLS Linear Regression model (which represents premium Tier 1 Metro Rates).
  4. Applies a Regional Market Index (RMI) multiplier depending on the selected city tier:
    • Tier 1 Metro: 1.00x (100% standard rate)
    • Tier 2 City: 0.65x (35% adjustment)
    • Tier 3 / Suburbs: 0.40x (60% adjustment)
  5. Formats the calibrated prediction in Lakhs or Crores (Indian numbering system) for natural readability.
